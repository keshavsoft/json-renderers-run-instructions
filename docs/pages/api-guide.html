Developer Guide

API Reference & Usage

How to invoke the engine with component keys, data, and options.

Installation

Via npm
npm install json-renderers-run-instructions
Via Browser CDN
<script type="module" src="https://keshavsoft.github.io/json-renderers-run-instructions/dist/v15/min.js"></script>

Core Engine Invocation

Pass the component main/sub key, data payload, and configuration options: 

const spec = renderFunc({
    instructionMainKey: "table",     // Step 1: Select main component
    instructionSubKey: "simple",     // Step 1: Select sub component
    data: { columns, data },         // Input data collection
    options: {                       // Step 5: Optional features
        serial: true,
        search: { showInput: true }
    },
    showLog: false
});

// Step 6: Pass completed spec to jsonToDom
window.ks.jsonToDom.appendToDom({
    jsonSpec: spec,
    targetHtmlId: "dom-render-container"
});
Parameters
Parameter Type Description
instructionMainKey String Main component family (e.g. "table", "select", "card").
instructionSubKey String Variant definition (e.g. "simple", "withFooter", "headerOnly").
data Object Input collections such as { columns, data }.
options Object Configuration options like serial, search, or custom controls.
showLog Boolean Optional debug flag (default false).
