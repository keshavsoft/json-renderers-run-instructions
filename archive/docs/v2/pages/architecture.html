Step-By-Step Process

How the Execution Engine Works

Detailed walk-through of the 6 steps transforming a component definition into a completed specification.

1

Select the Component

The application specifies the component using a main key and sub key. For example: table.simple.

instructionMainKey: "table",
instructionSubKey: "simple"
2

Retrieve the Definition

The engine retrieves the corresponding definition from spec-repo. The definition identifies:

  • The base specification (the structural template to use)
  • The required instructions (steps to generate nodes)
  • The available options (features that can be enabled or configured)
const definition = definitions[instructionMainKey]?.[instructionSubKey];
3

Prepare the Base Specification

The engine creates an independent copy of the selected base structure using structuredClone. This ensures no shared reference pollution and provides a fresh starting canvas for building the component.

const base = structuredClone(spec[definition.baseFromSpec]);
4

Execute the Instructions

The engine passes the instructions, base structure, and input data to json-renderers-run-instructions-steps. These instructions update the base specification according to the selected component definition.

runInstructions({
  instructions: definition.instructions ?? [],
  base,
  data,
  showLog
});
5

Apply Configuration Options

The engine passes the selected options to runOptions. Supported features (such as search boxes, serial numbers, custom action buttons, or styles) are applied to the generated specification.

runOptions({
  options,
  optionDefs,
  base,
  data,
  showLog
});
6

Return the Completed Specification

The engine returns the completed JSON specification. This output can then be passed to jsonToDom to create and display the actual HTML elements in the browser.

// 1. Return completed spec
return base;

// 2. Pass to jsonToDom for instant browser mounting
window.ks.jsonToDom.appendToDom({
  jsonSpec: spec,
  targetHtmlId: "dom-render-container"
});
