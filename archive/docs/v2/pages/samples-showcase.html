Supported UI Structures

One Engine, Multiple Components

The same execution flow builds tables, accordions, cards, lists, select dropdowns, and other supported UI structures. The component definition and its instructions determine what gets built.

Tables

Takes a base table structure, executes instructions to generate columns and rows from input data, and applies optional features like search boxes, serial numbers, and action buttons.

table.simple ↗ table.withFooter ↗ table.headerOnly ↗

Select Components & DataLists

Renders primitive option collections and dropdown elements directly from data arrays without manual HTML creation.

direct.select ↗ direct.dataList ↗

Cards & Accordions

Builds cards with headers, bodies, actions, and multi-section collapsible accordion panels.

container.card ↗ container.accordion ↗

Forms, Tabs & Modals

Supports complex structured UI components including responsive forms, tab panels, and popup dialog modals.

container.form ↗ container.tab ↗ container.modal ↗

Composite Master-Detail Systems

Combines multiple generated specifications into synchronized Master-Detail interfaces where clicking a table row edits data in a form with live autocomplete.

composite master-detail ↗
