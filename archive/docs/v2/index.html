Common Execution Engine • Pure JSON-to-DOM

From Component Definition to
Generated UI Specification

Building a user interface requires more than data. Each component needs a structure, a set of instructions, and configuration options that define how it should be built.

For example: Creating a table requires a base table structure, instructions to generate its columns and rows, and optional features such as serial numbers or search.

Explore The 6 Steps Live Interactive Studio

In Simple Terms

The Essence
1. Definition Tells what to build
Specifies component identity, base template, and available instructions.
2. Instructions Tell how to build it
Generates columns, rows, matrix elements, and dynamic nodes.
3. Options Customize the result
Enables serial numbers, search filters, and action buttons.
The Engine Executes & Returns Spec
Coordinates everything and delivers the finished JSON specification.
THE SOLUTION

An Instruction Execution Engine

json-renderers-run-instructions provides a common execution engine that takes a component definition and transforms it into a completed JSON specification.

Deterministic Pipeline

How It Works in 6 Steps

Hover over any card to inspect the phase details.

1 Input
Select the Component

The application specifies the component using a main key and sub key.

table.simple
2 Catalog
Retrieve Definition

The engine retrieves the definition from spec-repo, identifying base spec, instructions, and options.

definitions[mainKey]?.[subKey]
3 Clone
Prepare Base Spec

Creates an independent copy of the base structure via structuredClone as a fresh starting canvas.

structuredClone(spec[baseKey])
4 Execute
Execute Instructions

Passes instructions, base, and data to json-renderers-run-instructions-steps to update the specification tree.

runInstructions({ instructions })
5 Customize
Apply Options

Applies selected feature switches (serial numbers, search, actions) to the generated specification.

runOptions({ options })
6 Deliver
Return Specification

Returns the completed JSON specification, ready to be passed to jsonToDom for browser mounting!

jsonToDom.appendToDom()

Universality

One Engine, Multiple Components

The component definition and its instructions determine what gets built:

Tables

Generates columns and rows with optional search bars, serial numbers, and action buttons.

Accordions

Multi-panel collapsible accordions built dynamically from data objects.

Cards & Lists

Content cards, profile badges, and itemized data lists with zero manual DOM manipulation.

ARCHITECTURAL BOUNDARY

The Main Responsibility

json-renderers-run-instructions does not define every HTML component itself, nor does its main function directly create browser DOM elements.

Its True Responsibility:
To coordinate component definitions, execute their instructions, apply configuration options, and return the resulting JSON specification.
